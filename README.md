# CYBER_ALERT // "Your System is Hacked" Interface

A responsive, cyberpunk-themed static webpage featuring terminal aesthetics, glitch typography, CRT monitor scanline effects, live telemetry simulation, and interactive audio feedback.

## Features
- **Responsive Layout**: Designed for both mobile screens and high-resolution desktop monitors.
- **Glitch Typography**: Multi-layered CSS chromatic aberration glitch text animation on `"YOUR SYSTEM IS HACKED"`.
- **Matrix Rain Canvas**: Procedural matrix digital rain running smoothly in the background.
- **CRT Monitor Effects**: Scanlines, screen flicker, and vignette styling.
- **Web Audio API**: Built-in sound effects without external audio assets.
- **Interactive Terminal**: Real-time simulated logs and interactive "Force Purge Core" control.

## Project Structure
- `index.html` - Semantic layout and HUD elements.
- `style.css` - Visual styling, glitch animations, and responsive breakpoints.
- `script.js` - Matrix canvas animation, live system clock, and sound engine.

## Usage
Simply open `index.html` in any modern web browser or serve locally:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
